## 🎨 SkyTrail Brand & UI/UX

SkyTrail follows a **Luxury Astrology × Modern Technology × Ancient Wisdom** visual direction.

The UI is designed to feel premium, calm, readable and celestial without relying heavily on neon gradients or excessive visual effects.

### Luxury Golden Theme

| Color | Hex | Usage |
|-------|-----|-------|
| **Obsidian** | `#0B0A08` | Main background |
| **Espresso** | `#15120D` | Secondary background and navigation |
| **Dark Walnut** | `#1D1810` | Cards and interactive surfaces |
| **Bronze Black** | `#241E14` | Elevated cards |
| **Royal Gold** | `#D4AF37` | Primary accent, logo, borders and active states |
| **Champagne Gold** | `#F4D77B` | Highlights and subtle glow |
| **Antique Gold** | `#A67C20` | Deep gold accents |
| **Ivory** | `#FFF8E7` | Primary text |
| **Warm Gray** | `#B8AE9C` | Secondary text |
| **Taupe** | `#756D5F` | Muted text |
| **Dark Gold** | `#4A3A1D` | Borders and dividers |
| **Sage Gold** | `#A8B86B` | Success states |
| **Muted Rose** | `#C96B6B` | Error states |

### Recommended UI Color Balance

- **65%** Obsidian and Espresso backgrounds
- **20%** Dark Walnut and elevated surfaces
- **10%** Ivory typography
- **5%** Gold and status accents

Gold is intentionally used as a premium accent rather than as the dominant interface color.

### Typography

| Font | Usage |
|------|-------|
| **Cinzel** | Brand, logo and major headings |
| **Inter** | UI, navigation, buttons, cards and body text |
| **Cormorant Garamond** | Taglines, quotes and selected celestial messages |

### Layout Principles

- Dark-first interface with strong readability
- Clean card-based dashboard
- Thin gold borders instead of heavy glowing borders
- Floating bottom navigation
- Gold for active and important states
- Ivory for primary text
- Warm gray for secondary information
- Minimal use of gradients
- Gold-focused astrology charts
- Consistent spacing and visual hierarchy
- Premium presentation without making every component decorative

## 🚀 Installation

### Prerequisites

- **Windows 10/11**, **macOS 11+**, or **Linux**
- **Python 3.12** or higher
- **Ollama** for local AI: [Download Ollama](https://ollama.com/download)
- **Optional**: NVIDIA Nemotron API key: [NVIDIA Build](https://build.nvidia.com/)

### Setup Steps

#### 1. Clone the Repository

```bash
git clone https://github.com/AshwikBire/skytrail-desktop.git
cd skytrail-desktop
```

#### 2. Create Virtual Environment

```bash
python -m venv venv
```

#### 3. Activate Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**macOS/Linux:**

```bash
source venv/bin/activate
```

#### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

#### 5. Install Ollama Model

For local AI:

```bash
ollama pull qwen2.5:3b
```

#### 6. Run the Application

```bash
python src/main.py
```

**On Windows, you can also use:**

```bash
run_skytrail.bat
```

## 🎯 How to Use

### Generate Your Chart

1. Enter **Name**, **Birth Date** (`DD-MM-YYYY`) and **Birth Time** (`HH:MM`)
2. Select **City** from the dropdown or enter it manually
3. Choose **VEDIC** or **WESTERN** system
4. Select **Language** (`EN` / `हिं`)
5. Click **GENERATE CHART**

### Explore Features

- **Predictions**: Face, Career, Marriage, Children, Success and Personality
- **Yogas**: 50+ Vedic Yoga detection
- **Panchang**: Daily Vedic calendar
- **Muhurta**: Auspicious event dates
- **Transits**: Current planetary transits
- **Matchmaking**: Compatibility with others
- **AI Reading**: AI-generated personalized readings
- **Astrocartography**: Favorable worldwide locations

### AI Setup

#### Local AI with Ollama

Start the Ollama server and keep it running:

```bash
ollama serve
```

#### Cloud AI with Nemotron

1. Get an API key from [NVIDIA Build](https://build.nvidia.com/)
2. Open **Settings** → **API Settings**
3. Enter the API key beginning with `nvapi-`
4. Click **Test Key** → **Save Key**
5. Toggle to **AI: NEMOTRON**
